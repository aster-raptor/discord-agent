目的:
Telegramチャットから、参加者が「どのサービス・プロトコル・取引所・銘柄・テーマ」に注目しているかを抽出し、
1. 何に注目が集まっているか
2. なぜ注目されているか
3. 市場に対してポジティブかネガティブか
4. その話題を受けて、投資家・トレーダーとして何をすべきか
を整理してください。

重要なルール:
- 雑談、ノイズ、内輪ネタはできるだけ除外してください。
- 「サービス名」「プロトコル名」「取引所名」「銘柄名」「テーマ名」を正規化してください。
  例: 表記ゆれ、英字/カナ、略称を統合する。
- 単なる一言言及ではなく、会話の盛り上がり、反応数、具体性、価格材料性を踏まえて重要度を判断してください。
- 事実と推測を分けてください。
- 必ずチャット内の根拠をタイムスタンプ付きで引用してください。
- 根拠が薄いものは「確度: 低」と明記してください。
- 外部知識は補助的に使ってよいですが、主判断はこのチャット内容に基づいてください。
- 不明な点は断定せず「チャット上では不明」と書いてください。

出力形式:
まず全体サマリーを5-10行で書く。

次に、注目対象を重要度順に表で整理する。
列は以下:
- 順位
- 注目対象
- カテゴリ
- 注目度
- センチメント（強気 / 弱気 / 中立 / 混合）
- 注目理由
- 想定される市場インパクト
- 取るべきアクション
- 確度
- 根拠発言（タイムスタンプ付き）

その後、以下のセクションを出してください。

1. 注目サービス別の詳細分析
各サービスについて以下を整理:
- 概要
- チャット参加者が注目した理由
- 価格材料 / ファンダ材料 / リスク材料
- 会話から読み取れる短期センチメント
- 会話から読み取れる中期示唆
- ウォッチすべき指標

2. 市場全体のセンチメント分析
- このチャット全体は市場に対してポジティブかネガティブか
- その理由
- 強気材料と弱気材料の比較
- リスクオン / リスクオフのどちらに傾いているか

3. 実務アクション提案
以下の3軸で提案してください。
- 今すぐ確認すべきこと
- 今日中に監視すべきこと
- 中期で仕込むなら見るべきこと

4. 最後に、投資判断に使える形で
- 最重要ウォッチ対象 Top 3
- 最も危険な対象 Top 3
- 最も期待先行の対象 Top 3
を箇条書きでまとめてください。

より精度を上げたいなら、出力をJSON寄りに縛る版も有効です。後続で自動処理するならこちらです。

C:\Develop\data-acquisition\telegram\data\chat-1001322850199\2026-04-02.txt を読み、
Telegram会話から投資判断に有用な注目対象を抽出してください。

要件:
- 注目対象は services 配列にまとめる
- 各要素は以下のキーを持つこと
  - name
  - normalized_name
  - category
  - attention_score_0_to_100
  - sentiment
  - bullish_reasons
  - bearish_reasons
  - why_people_care
  - recommended_actions
  - confidence
  - evidence
- evidence は {timestamp, speaker, quote} の配列にする
- market_summary には市場全体のセンチメントを入れる
- action_plan には immediate / intraday / swing の3区分で提案を書く
- noise_topics には重要でない雑談テーマを入れる
- hallucinationを避け、根拠が弱い場合は confidence を low にする
- JSONの後に人間向け要約を付ける

特に重視する観点:
- 何が話題になったか
- 価格や需給に直結する材料か
- ハック、バイバック、上場、入出金停止、TGE、vault、エアドロ、オラクル問題などのイベント性
- 会話の温度感から見た短期需給
